## Getting Started
Follow these steps to set up and run the Godot project in this repository

<p align="right">(<a href="#readme-top">up</a>)</p>

### Prerequisites
Before starting, please ensure that you have the following software installed
* [Godot Engine 4.6.3](https://godotengine.org/download/archive/4.6.3-stable/): this project was created and tested with this particular version. Different versions may cause compatibility errors.

<p align="right">(<a href="#readme-top">up</a>)</p>

### Install
1. Clone the repository
   ```sh
   git clone https://github.com/createlab-univaq/pisco.git
   ```
2. Open Godot 4.6.3
3. Click on **Import**
4. Select from Godot's file picker the **project.godot** file inside this repository folder
5. Click on **Import & Edit**
